# icons/ — Iconos Nativos PWA

## Propósito
Alojar los iconos de la aplicación web progresiva para su instalación en Android, iOS y computadoras de escritorio.

## Archivos
- `icon-192.png`: Icono estándar de 192x192 px.
- `icon-512.png`: Icono de alta definición para splash screens y lanzadores.
- `icon-maskable-192.png`: Icono adaptable a máscaras circulares/cuadradas de Android.
- `icon-maskable-512.png`: Icono adaptable HD.
- `apple-touch-icon.png`: Icono táctil para dispositivos Apple iPhone y iPad.
