# src/gui/ — Capa de Presentación e Interacción

## Propósito
Controlar los eventos del usuario en smartphones, interacción táctil, gestos de swipe, inmersión y flujo de instalación PWA.

## Archivos
- `app-controller.js`: Orquestador principal de la interfaz de usuario, navegación entre biblioteca y modo lectura.
- `text-mode-controller.js`: Gestor de extracción de texto y tipografía grande para adultos y personas mayores.
- `filter-modal-controller.js`: Controlador del modal y sliders de descanso visual.
- `pwa-manager.js`: Detección del banner de instalación nativo (`beforeinstallprompt`) y registro del Service Worker.
