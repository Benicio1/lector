# src/gui/ — Capa de Presentación e Interacción

## Propósito
Controlar los eventos del usuario en smartphones, interacción táctil, gestos de swipe, inmersión y flujo de instalación PWA.

## Archivos
- `app-controller.js`: Orquestador principal de la interfaz de usuario, navegación entre biblioteca y modo lectura, sliders y modal de filtros.
- `pwa-manager.js`: Detección del banner de instalación nativo (`beforeinstallprompt`) y registro del Service Worker.
